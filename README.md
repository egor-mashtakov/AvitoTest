# Финальная модель
Решение DS Bootcamp Avito Classical ML

## Суть решения

Для каждой cookie модель оценивает вероятность автоматизированного сбора данных. События связываются с cookie и ограничиваются её суточным окном от `window_start_ts` включительно до `window_end_ts` не включительно.

Модель использует несколько групп признаков.

- Объём, типы и разнообразие событий
- Темп действий, интервалы и переходы между событиями
- Распределение активности по часам и внутри окна
- Платформу, браузер, операционную систему и признаки User Agent
- Сглаженный target encoding категорий по событиям
- Скорость, длину и форму движения курсора
- Возраст cookie на начало окна

Повторы событий сохраняются и влияют на счётчики. Платформа, браузер и операционная система без значения получают категорию `unknown`, другие пропуски учитываются доступными агрегатами, а отсутствующие числовые признаки заполняются нулём. `cookie_id` исключён из матрицы, а `item_id` используется только через сглаженный target encoding. Обучающие target encoding строятся с cross fitting, чтобы строка не использовала собственную метку.

Baseline использует только возраст cookie, общий объём и разнообразие событий, а также счётчики типов событий. Обе модели используют одинаковые параметры XGBoost, поэтому сравнение показывает вклад расширенного набора признаков.

## Валидация и результаты

Пять расширяющихся временных фолдов обучаются на датах с 6 по 16 апреля 2026 года. Каждый фолд проверяется на следующем дне. Отдельный holdout охватывает даты с 17 по 19 апреля. Test относится к более позднему периоду и не имеет целевых меток в доступных данных.

| Метрика | CV baseline | CV расширенная | Holdout baseline | Holdout расширенная |
| --- | --- | --- | --- | --- |
| Precision при Recall ≥ 70% | 0.2609 | 0.8319 | 0.2673 | 0.8819 |
| Average Precision | 0.5152 | 0.8015 | 0.4754 | 0.7842 |
| ROC-AUC | 0.8445 | 0.9376 | 0.8302 | 0.9413 |
| Recall при FPR ≤ 1% | 0.3316 | 0.7061 | 0.2438 | 0.7000 |

Holdout и CV дают локальную оценку. Результат на скрытой тестовой выборке может отличаться.

## Воспроизводимость

Python, NumPy, StratifiedKFold и XGBoost используют seed 42. Для фиксации hash seed запусти Jupyter с `PYTHONHASHSEED=42`.

```sh
uv sync
PYTHONHASHSEED=42 uv run jupyter notebook final_model.ipynb
```

Ноутбук сохраняет обученную модель в `results/final_model.json` и предсказания в `results/submission.csv`.

## Файлы

- `final_model.ipynb` содержит весь pipeline и сравнительную таблицу
- `data/train.csv` содержит обучающие метки
- `data/test.csv` содержит cookie для предсказания
- `data/events.csv` содержит события
- `results/final_model.json` содержит обученную модель
- `results/submission.csv` содержит предсказания для test
- `pyproject.toml` содержит зависимости
- `.python-version` задаёт версию Python
